# PRD editor interactions

- In local editing mode, beyond the PRD panel controls above, limit block editing to the requested Notion-like interactions: paste Markdown into supported blocks; type `/` to insert text, H1-H4, divider, callout, quote, nested bulleted list, or nested numbered list blocks; and convert existing blocks among these types. Preserve existing text and list structure when converting; ask before a conversion would discard content. Preserve unsupported pasted Markdown as text instead of silently dropping it. Let the panel scroll vertically, with a scrollbar using the project's existing color at 40% opacity. Follow the project's visual language rather than copying Notion's branding, colors, or unrelated features.
- In all full-page and component PRDs, allow continuous text selection across multiple lines and blocks in the current content tab, using mouse dragging or keyboard selection, followed by normal Copy/Ctrl+C. Do not restrict selection to one block. Within the local editor body, Ctrl+A selects the current tab body. Preserve text order, line breaks, and list indentation in copied text; exclude editor controls, hidden metadata, and hidden duplicate headings. Selection and copying must not modify or save the document. Preserve existing block editing, list conversion, Markdown paste, undo, and drag-handle behavior; deployed read-only PRDs must also support multiline selection and copying.
- In local editing mode, provide a drag handle for reordering existing PRD blocks within the same parent level. Move a parent block together with all its nested children; do not change their text, block types, or nesting. Do not add cross-level or cross-page dragging, column layouts, or other Notion interactions. Treat a completed reorder as a manual PRD edit and auto-save it to the same project PRD file under the file-saving rules below.
- While the local PRD editor has focus, bind `Ctrl+Z` to multi-step undo for text edits, Markdown paste, block conversion, list nesting, and drag reordering. Restore the preceding document state and auto-save the undone result to the same `.md` file. Keep undo history for the current editing session; do not intercept `Ctrl+Z` outside the PRD editor.
