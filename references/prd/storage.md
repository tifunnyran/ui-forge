# PRD storage and synchronization

- For local editing, first have the user grant browser write access to `src/prd/` as a directory, then resolve each mapped `.md` file automatically; do not ask the user to choose a file when switching pages or components, including an empty PRD. After access is granted, auto-save edits to the mapped file and report success only after the write completes. If a file changed outside the panel since it was loaded, stop before overwriting and ask the user how to resolve the difference. If direct local directory writing is unavailable or permission is denied, keep unsaved work visible and ask how to proceed; do not silently use browser-only storage or add a backend service.
- Treat the corresponding project PRD file as the durable source of truth. After a refresh, page revisit, or preview restart, load its latest saved contents before showing the panel; never replace saved edits with an initial fixture or in-memory default. In local editing mode, if directory access needs renewed browser permission, request it instead of presenting stale content as current. Warn before leaving or refreshing while an auto-save is pending, and never report an edit as permanently saved until its file write succeeds.
- If enabled during a first `extract`, complete the style-preserving extraction before adding the editor as a separate `extend` step. Do not change the original frontend styles to accommodate the editor.
- For every prototype frontend change handled by this skill after PRD mode is enabled, compare the affected page and component with their existing PRD in the same task. Leave any semantically consistent PRD content unchanged, including manually edited text; add only missing content required by the approved UI change. If existing PRD content conflicts with the prototype or a previously confirmed requirement, show the exact difference and ask the user to resolve it before editing either side. Do not scan or rewrite unrelated pages. This workflow cannot monitor frontend code changes made outside a task using this skill, and it does not add runtime AI, backend services, or network requests.
